# AI 接入

LayoutSculpt 支持本机 Codex 与外部 API 两条接入方式；目前直接 API 使用 DeepSeek 官方接口。两条路径共用户型识别、结构复核、家具和材质创作流程，按所选模型的实际能力开放功能，不要求所有 AI 请求都经过本机 Codex，也不代表支持任意服务商的自定义 API 地址。

打开左侧「素材库」下方的「AI 接入」，或访问工作台页面 `http://127.0.0.1:8000/#ai`。此处接入的是现有的结构化设计流程，不是额外的图片生成服务。

## 配置与使用

1. 简单使用选「DeepSeek API」，粘贴官方控制台的 API Key，点击「连接并使用 DeepSeek API」。自动检测、选模型并保存，不需要先测试再单独保存。
2. 进阶使用选「Codex」。已有本机 CLI 可直接点击连接；没有时准备独立环境，再在官方页面完成登录。选择卡片本身不会修改默认来源。
3. 连接成功后即可生成。若要指定默认模型，在「模型与更多设置」读取目录并选择，再点击连接按钮保存。各生成表单仍允许临时换来源、模型和推理强度。

DeepSeek 固定连接官方 `https://api.deepseek.com`。保存前后端验证连接和模型，成功才原子更新设置，失败保留原配置。高级设置的「读取可用模型」只检测、不保存密钥，也不创建生成任务。

DeepSeek 的模型名称、图片能力、推理档位和输出上限来自官方 `/models` 返回的信息，不把固定旧模型名称当成可用模型。未声明图片能力的模型不会被当成视觉模型使用。默认选择文字模型时，户型生成表单会优先选该来源中可用的视觉模型；没有视觉模型时会阻止提交并给出提示。

## 流程范围

- 户型识别、AI 结构复核、人工设计中的局部复核：需要支持图片理解的模型。
- 家具 DIY：无参考图时可使用文字模型，上传参考图后需要视觉模型。
- 墙面与地板材质 AI：使用文字模型生成材质配方，本地继续烘焙贴图、校验和保存。
- 任务数据库保留完整来源标识。`deepseek::模型ID` 用于区分直接 API 请求；原有未带此前缀的 Codex 任务继续走 Codex，不受默认来源变化影响。
- 后端的 Pydantic 约束、几何校验、结构核对、版本保存和 GLB 构建保持同一套流程。API 服务不能绕过项目的数据校验，也不会执行模型返回的代码。

## 密钥与数据

连接记录位于当前数据目录的 `ai/connections.json`，默认属于已被 `.gitignore` 排除的 `data/`。

Windows 使用当前系统账户的 DPAPI 加密密钥；其他系统使用 Fernet 与权限为 `0600` 的本机主密钥文件。不能将这些文件视作可公开分享的配置：不要提交或分享整个本地数据目录。Windows 的加密记录迁移到其他系统账户后需重新填写密钥。

设置响应只返回「是否已配置」和模型等非敏感元数据。浏览器不会将输入的密钥写入 localStorage、sessionStorage、页面地址状态或设计草稿；保存后立即清空密码框。留空会保留旧密钥，输入新密钥需要重新测试。「移除 DeepSeek 连接」会移除当前加密记录并切回 Codex。已开始的请求使用其捕获的连接，后续 DeepSeek 请求需重新配置后才能继续。

使用 DeepSeek 时，设计要求、生成所需的结构数据和必要参考图会发送给 DeepSeek。Codex 同样沿用本机已经配置的推理服务，不代表离线推理。

## 常见情况

### 简单接入与进阶接入

首次打开接入页优先展示 DeepSeek API；已有用户仍显示其已保存的默认来源。填写密钥并点击「连接并使用 DeepSeek API」即可在一次请求中完成检测、选择默认模型和保存。检测失败不覆盖原设置，网络中断导致保存结果不确定时先重新读取状态，不盲目重复提交。模型和移除密钥等操作收在「模型与更多设置」。

DeepSeek 的文字模型适合无参考图的家具、墙面和地板材质设计；是否支持上传户型和参考图片，以 `/models` 的实际能力为准。接入不等于验证付费生成额度，检测不会发起推理任务。

### Codex：复用本机，或项目独立管理

- 已有 Codex 的用户可以点击「连接并使用 Codex」，复用本机 CLI、登录和配置，不强制安装。首次检测只检查程序是否存在，不读取或回显密钥；实际连接时验证协议和模型目录。
- 没有 CLI 时可点击「准备项目独立环境」。已有用户也可以在「环境、更新与恢复」里主动切换；历史项目专用 CLI 的共享配置模式继续保留，不自动迁移账号。
- 独立模式的程序位于 `data/runtime/packages/codex/`，配置和登录位于 `data/runtime/codex-home/`。仅给项目子进程设置独立 `CODEX_HOME`，清理继承的 Codex/OpenAI 认证和配置环境变量，保留系统与代理环境，不修改系统 PATH、全局配置或本机原 CLI。
- 独立模式使用 CLI 的文件凭据存储，避免共用系统凭据槽。Windows 为独立目录设置当前账户 ACL，其他系统使用目录权限 `0700`。这些文件包含敏感登录信息，不能分享或提交 Git；它们与 DeepSeek 的加密密钥存储机制不同。
- 页面登录使用 CLI 的 `account/login/start`，打开官方认证入口。账号授权由用户在官方页面完成，后台收到匹配的完成通知后，页面自动检测并保存连接。链接只保留在内存，不写入日志/数据库/页面地址状态，接口禁止缓存；可以取消，10 分钟未完成自动结束等待。共享模式登录会使用本机共享凭据，界面明确提示。
- 独立模式不会复制本机登录文件，首次需单独登录；CLI 更新保留同一配置目录。登录失效时重新登录。它提供配置隔离，不代表操作系统沙箱，也不能绕过账户、网络或组织政策。

### 更新与恢复

「环境、更新与恢复」收纳版本检测、重连、准备独立环境、恢复上一版和恢复本机 CLI；正常连接无需操作这些选项。

- 用户点击后才从官方 npm 平台包下载，校验摘要并有界解压，不执行远程安装脚本。
- 普通更新允许当前任务继续执行：先下载、校验，用临时独立配置验证候选 CLI，然后等待空闲再切换。下载和等待期间可以取消，切换期间短暂阻止新的 Codex 请求。整次准备有 15 分钟时限，超时保留原安装。
- 切换失败恢复原 CLI 选择；恢复上一版同时恢复该版本记录的配置模式，不用旧快照覆盖新登录令牌。独立配置目录保留。
- 新安装尚未登录时提示「需要登录」，不会把安装完成当作可以生成。切换环境/登录前要求当前 Codex 任务结束，避免任务中途改变身份。
- 页面关闭不会取消正在进行的安装或登录。重新进入可读取当前进度；服务重启会将中断安装标记为失败，用户可重试。登录需重新发起。
- 这里通过 CLI 的 app-server 通信，不控制 Codex 桌面窗口；协议检测通过不等于所有模型推理权限已验证。


| 提示 | 处理方式 |
| --- | --- |
| 密钥无效或已失效 | 填写正确密钥后点击「连接并使用」 |
| 余额不足／请求过于频繁 | 检查 DeepSeek 账户或稍后重试；不会自动改用 Codex |
| 没有支持图片的模型 | 家具／材质文字设计仍可使用；户型识别请换用视觉模型或 Codex |
| 连接或响应超时 | 检查网络与本机代理，已有设计及成功阶段仍保留 |
| 设置在其他窗口更新 | 刷新设置后再提交，防止覆盖其他窗口的修改 |
| 本机连接记录无法读取 | 继续使用 Codex，或重新填写 DeepSeek 密钥并保存 |

直接 API 请求优先使用进程的显式代理配置；未配置时继承 Windows 系统手动 HTTPS 代理。不会修改系统代理或 Codex 全局配置。

## 验证

`backend/tests/test_ai_connections.py` 使用受控 HTTP 传输验证真实请求格式、密钥加密、失败时不覆盖配置、版本冲突、来源隔离、图片能力检查、取消传播，以及识别／复核／家具／材质完整流程。测试替身只由测试代码注入，不提供运行时模拟开关。

`backend/tests/test_codex_installer.py` 验证官方包选择、摘要校验、解压路径边界、取消清理、单任务去重、活动任务保护、切换失败恢复、重启后版本选择以及本机 CLI 文件保持原样。平台支持 Windows / macOS 的 x64 与 ARM64 原生包；当前实际安装与浏览器验收在 Windows x64 上完成，macOS 仍待实机验证。

实际 DeepSeek 账户的权限、余额与网络连接需要用户在接入页用自己的密钥测试。不要把模拟服务通过描述为真实账户已经连接。

接口参考：[模型目录与能力](https://api-docs.deepseek.com/api/list-models/)、[图片理解](https://api-docs.deepseek.com/guides/vision/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)、[推理模式](https://api-docs.deepseek.com/guides/thinking_mode/)。
