# AI 接入

打开左侧「素材库」下方的「AI 接入」，或访问开发页面 `http://127.0.0.1:5173/#ai`。此处接入的是现有的结构化设计流程，不是额外的图片生成服务。

## 配置与使用

1. 选择「本机 Codex」或「DeepSeek API」。选择卡片只切换编辑面板，不立即修改默认来源。
2. Codex 沿用本机 CLI 的登录和配置。DeepSeek 需要从官方控制台获取个人密钥，填入页面的密码框；只连接 `https://api.deepseek.com`，不将已保存的密钥发送到任意自定义地址。
3. 点击「测试连接并读取模型」。此操作仅读取模型目录，不创建生成任务，也不保存输入的密钥。
4. 从实际可用的模型中选择默认模型，点击「保存并设为默认」。保存前后端会再次验证连接及模型，成功后才原子更新设置；失败保留原配置。
5. 各生成表单的「AI 来源」允许单次切换，不修改默认来源。模型和推理强度按所选来源的实际能力显示，不自动跨服务重试。

DeepSeek 的模型名称、图片能力、推理档位和输出上限来自官方 `/models` 返回的信息，不把固定旧模型名称当成可用模型。未声明图片能力的模型不会被当成视觉模型使用。默认选择文字模型时，户型生成表单会优先选该来源中可用的视觉模型；没有视觉模型时会阻止提交并给出提示。

## 流程范围

- 户型识别、AI 结构复核、人工设计中的局部复核：需要支持图片理解的模型。
- 家具 DIY：无参考图时可使用文字模型，上传参考图后需要视觉模型。
- 墙面与地板材质 AI：使用文字模型生成材质配方，本地继续烘焙贴图、校验和保存。
- 任务数据库保留完整来源标识。`deepseek::模型ID` 用于区分直接 API 请求；原有未带此前缀的 Codex 任务继续走 Codex，不受默认来源变化影响。
- 后端的 Pydantic 约束、几何校验、结构核对、版本保存和 GLB 构建保持同一套流程。API 服务不能绕过项目的数据校验，也不会执行模型返回的代码。

## 密钥与数据

连接记录位于当前数据目录的 `ai/connections.json`，默认属于已被 `.gitignore` 排除的 `data/`。

Windows 使用当前系统账户的 DPAPI 加密密钥；其他系统使用 Fernet 与权限为 `0600` 的本机主密钥文件。不能将这些文件视作可公开分享的配置：不要提交或分享整个本地数据目录。Windows 的加密记录迁移到其他系统账户后需重新填写密钥。

设置响应只返回「是否已配置」和模型等非敏感元数据。浏览器不会将输入的密钥写入 localStorage、sessionStorage、定位链接或设计草稿；保存后立即清空密码框。留空会保留旧密钥，输入新密钥需要重新测试。「移除 DeepSeek 连接」会移除当前加密记录并切回 Codex。已开始的请求使用其捕获的连接，后续 DeepSeek 请求需重新配置后才能继续。

使用 DeepSeek 时，设计要求、生成所需的结构数据和必要参考图会发送给 DeepSeek。Codex 同样沿用本机已经配置的推理服务，不代表离线推理。

## 常见情况

### CLI 版本、连接诊断与恢复

本机 Codex 面板提供「检测环境并读取模型」「安全重连」「检查更新」和直接下载安装。Windows 和 macOS 都调用 CLI 的 `app-server`，不连接桌面客户端窗口。

- 环境检测读取 `codex --version`，验证 app-server 初始化、认证状态与模型目录。界面显示安装版本、系统架构、检测时间和具体修复建议。模型目录可读取不代表模型推理权限或余额已验证；检测不会创建推理任务。
- 未安装、无执行权限、未登录、协议不兼容、超时和连接中断分别提示处理方法。模型目录读取遇到明确的临时连接故障最多重试一次，不跨来源调用。
- 安全重连只关闭本项目创建的 app-server，不关闭其他 Codex CLI 或桌面客户端。覆盖请求准备阶段在内的本机生成任务、活动线程或待响应请求存在时，会拒绝重连。已有设计和默认来源保留。
- 检测发现 CLI 文件与当前运行进程启动时不一致时，要求先安全重连，再验证新版本，不把磁盘上的新版本当作已验证的运行版本。
- 检查更新仅请求固定 npm 包 `@openai/codex` 的 `latest` 元数据，无需 API 密钥；设置超时、响应大小限制及短时缓存。点击「一键更新」或「下载安装稳定版」后才创建后台安装任务，不在页面加载时自动升级。
- 下载根据当前系统与架构选择 OpenAI 官方 npm 原生平台包，限定 HTTPS 软件源，验证发布元数据中的 SHA 完整性，再有界解压。不运行 npm 安装脚本、远程 shell 脚本，也不需要额外安装 Node.js 或 Python。
- 默认安装在项目数据目录的 `runtime/packages/codex/`，下载缓存在 `runtime/downloads/`。项目位于 D 盘时下载、解压和安装均在 D 盘。项目专用版本沿用本机登录与服务配置，原本机 CLI 不会被覆盖，不修改系统 PATH 或其他软件的 CLI。
- 页面显示实际下载字节数、总大小（服务器提供时）以及校验、解压、验证和重连步骤。任务不依赖当前 HTTP 连接；刷新或重新进入页面仍可查询进度。断网后可重试，已完成且校验通过的下载会复用。可在切换前取消，取消会清理未完成下载和本次未启用的安装目录。
- 新版本先验证 `--version` 与 app-server 握手，再切换本项目使用的可执行文件并重新读取模型。切换期间阻止新本机生成任务；切换时仍有任务或请求则拒绝操作。复检失败会恢复原连接，未登录时明确提示登录，不把缺少认证当成软件安装失败。
- 「恢复上一版」在已有上一份项目专用版本时显示；「恢复原本机 CLI」切回原来的本机命令。版本选择记录在 `data/runtime/active.json`，只包含本地相对路径和版本，不含账号、密钥。服务重启后继续使用已选的项目版本。
- 展开「查看手动升级方法」仍可复制 npm / Homebrew 命令，按原安装方式在终端升级后安全重连。此功能只管理 Codex CLI，不管理 Python、Node.js 或电脑全局环境。
- 本机最近通过协议检测的版本记录保存在 `data/ai/codex-compatibility.json`，只包含版本、平台、架构和检测时间，不含账号、密钥或本机路径。这是本机协议检测记录，不是所有系统、模型或完整推理流程的认证。升级失败可按原安装工具恢复先前版本，再重新检测。
- Codex 检测失败且已配置 DeepSeek 时，可以点击检查备用连接，测试并保存后供新任务使用；不会自动把正在进行的任务转交其他服务。

命令和协议参考：[OpenAI Docs · app-server](https://developers.openai.com/codex/app-server)、[CLI 认证命令](https://developers.openai.com/codex/cli/reference)、[官方升级命令示例](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)。

| 提示 | 处理方式 |
| --- | --- |
| 密钥无效或已失效 | 重新复制个人密钥，测试成功后再保存 |
| 余额不足／请求过于频繁 | 检查 DeepSeek 账户或稍后重试；不会自动改用 Codex |
| 没有支持图片的模型 | 家具／材质文字设计仍可使用；户型识别请换用视觉模型或 Codex |
| 连接或响应超时 | 检查网络与本机代理，已有设计及成功阶段仍保留 |
| 设置在其他窗口更新 | 刷新设置后再提交，防止覆盖其他窗口的修改 |
| 本机连接记录无法读取 | 继续使用 Codex，或重新填写 DeepSeek 密钥并保存 |

直接 API 请求优先使用进程的显式代理配置；未配置时继承 Windows 系统手动 HTTPS 代理。不会修改系统代理或 Codex 全局配置。

## 验证

`backend/tests/test_ai_connections.py` 使用受控 HTTP 传输验证真实请求格式、密钥加密、失败时不覆盖配置、版本冲突、来源隔离、图片能力检查、取消传播，以及识别／复核／家具／材质完整流程。测试替身只由测试代码注入，不提供运行时模拟开关。

`backend/tests/test_codex_installer.py` 验证官方包选择、摘要校验、解压路径边界、取消清理、单任务去重、活动任务保护、切换失败恢复、重启后版本选择以及本机 CLI 文件保持原样。平台支持 Windows / macOS 的 x64 与 ARM64 原生包；当前实际安装与浏览器验收在 Windows x64 上完成，macOS 仍待实机验证。

实际 DeepSeek 账户的权限、余额与网络连接需要用户在接入页用自己的密钥测试。不要把模拟服务通过描述为真实账户已经连接。

接口参考：[模型目录与能力](https://api-docs.deepseek.com/api/list-models/)、[图片理解](https://api-docs.deepseek.com/guides/vision/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)、[推理模式](https://api-docs.deepseek.com/guides/thinking_mode/)。
