# 人工设计与交付优化（2026-11-02）

## 用户入口

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| 拖动摆放提示 | 平面 / 三维人工设计，直接拖动家具 | 一条轻提示显示房间边界、墙体、家具重叠或门口通行问题；不自动挪动家具 |
| 家具联动 | 选中家具 → 家具联动 | 选择跟随的家具。绑定时保持原位；之后跟随移动、旋转，顶面物品随高度变化 |
| 陈设联动 | 展示陈设 → 展开一组 → 跟随家具 | 真实陈设网格同步移动；区域陈设仍按组调整，不自动拆分床品、餐具 |
| 商品尺寸试摆 | 选中家具 → 按商品尺寸试摆 | 按厘米输入宽、深、高，应用后可撤销；使用相近模型，不声称复刻商品外观 |
| 我的家具 | 商品尺寸试摆 → 存到我的家具；左侧添加 → 我的家具 | 保存独立模板，再选择位置放入其他户型。移除记录不删除场景中的家具 |
| 单件 AI 建议 | 选中家具 → 用一句话调整这件家具 | 沿用已接入的 Codex / API 模型；返回建议，用户可预览、取消、应用和撤销 |
| 版本比较与恢复 | 我的任务 → 比较 | 具体对象差异、按需展开同镜头三维切换；恢复为新版本，保留当前版本及草稿 |
| 家庭方案册 | 导出成果 → 导出家庭方案册 | 下载单个 HTML，含全屋及各空间图、平面图、墙长、面积、家具和照明清单；离线打开或打印 PDF |

高级操作默认折叠，拖动时不新增整屏进度条。权限管理不在本次改动范围。

## 数据与恢复

- 依附关系使用 `parent_furniture_id` 指向稳定的家具 `edit_id`，随草稿、版本及项目成果包保存。前后端检查失效引用、循环及重复 ID。
- 删除父家具会解除联动并保留跟随物品的位置；锁定跟随物品时禁止间接移动。显式移动孩子优先于父家具联动，防止重复位移。整个编辑步骤支持撤销。
- `data/studio.sqlite3` 新增 `furniture_presets` 表，最多 200 条，移除场景坐标、锁定和依附身份，保留尺寸及不可变素材副本。完整本机备份覆盖数据库及模型；单项目成果包不包含整个“我的家具”列表。
- AI 单件建议使用项目内 `skills/furniture-local-edit/SKILL.md`、LangChain 与 LangGraph 的“建议 → 校验”流程。只返回一个家具，不直接写项目。其他对象和建筑结构保持原样；款式只允许同类可用目录。取消请求会取消等待，失效结果不能覆盖后续草稿。
- 有跟随物品的父家具暂不接受 AI 单件修改，以保持“仅改选中对象”的边界；手动调整仍支持整组联动。提示在调用模型前返回。
- 恢复历史设计创建新的建模任务，不覆盖原版本。对比忽略纯编辑元数据；无稳定 ID 的早期数据按原顺序匹配，不能作为审计级差异依据。

## 相关清理与修复

- 报告复用已有 SVG 绘图函数，移除第二套平面绘制代码，墙长改为明细列；隐藏家具不混入展示清单。
- 三维可同步能力按实际绑定网格判断；缺少陈设网格时不能假报已同步。新绑关系本身不触发几何重建。
- 三维手势提交前同时检查跟随物品，避免只检查父家具。门窗洞口与实体墙分开判断，不把完整洞口内的物品误报为撞墙。
- 修复建议预览期间误保存、尺寸应用后折叠项重置、重复读取个人家具、导出 StrictMode 取消标记、取消导出后镜头恢复、跨项目导出影响新场景、三维比较失败后无法切换等问题。
- 陈设属性按需挂载，减少未展开时的表单节点；版本数量统计默认收起，差异统计共用相同判断。
- 方案册图片按最大边约 1800 像素重新渲染，高质量 JPEG 内嵌；受像素倍率上限影响，极小窗口输出可能小于此尺寸。截图后恢复原渲染倍率与镜头。
- `.gitignore` 已覆盖本机数据库、模型副本、验收数据、日志和构建产物，无需增加重复忽略规则。
