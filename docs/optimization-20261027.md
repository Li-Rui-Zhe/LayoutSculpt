# 示例空间与交互体验更新

## 林间光庭

- 基于真实 GLB 重做原创示例，扩展露台后轮廓面积为 93.2㎡，七个功能分区保持不变。
- 露台改为矮基座、透明栏板和古铜扶手；增加花园茶席、静水石钵、层叠植栽与庭院矮灯。
- 洞石细孔纹理、软方织物靠垫、雕塑落地灯、床头灯、拱镜与陶器均由本地脚本构建，不依赖外部图像服务。
- 明确设置木材、石材、树叶的非金属属性，避免 glTF 缺省值产生不自然光泽；树叶合并、同类家具复用几何。
- 样板晴天按固定窗向布光，普通用户项目的日光参数不受影响。保留晴天、日落、夜晚，移除阴天；旧阴天设置回退晴天。
- GLB 内容 revision 更新，避免浏览器继续使用旧模型。面积根据轮廓计算，不写死宣传数值。

## 验证与发布

```sh
python scripts/build_showcase.py
python -m pytest backend/tests/test_showcase.py backend/tests/test_low_walls.py -q
pnpm test:frontend
pnpm build
node scripts/review/verify_showcase.mjs
```

构建检查房间、墙体、门窗截面和家具放置。浏览器验收覆盖三种光照、完整墙体、剖切、俯视及手机布局，并拦截写入、屏蔽实际任务列表。示例属于原创展示场景，装饰细节不是识别准确率或实际施工效果的承诺。复制示例后的可编辑对象边界见 [设计工作流](design-workflows.md)。

本地数据库、原图、DIY 产物、修正版用户任务、运行日志和鉴权配置继续由 `.gitignore` 排除；仓库仅分发代码、官方模型与公开示例截图。
