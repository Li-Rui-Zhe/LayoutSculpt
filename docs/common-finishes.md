# 常用装修材质

官方墙面、地板各保留 10 款代表性材质，使用项目内色彩与法线贴图，共用于素材库、三维预览、DIY 和 GLB 导出。

- 墙面：纯白、暖白、浅灰乳胶漆，米灰艺术漆、暖灰微水泥，浅橡木/胡桃木饰面，亚麻墙布，瓷白亮光墙砖、浅米大理石纹墙砖。
- 地板：原木、浅色橡木、胡桃直铺与橡木人字拼，奶油柔光砖、暖灰哑光砖、浅灰大理石纹地砖，米色洞石、浅米水磨石、暖灰微水泥。

浅灰大理石纹地砖支持人工设计中的实际块材铺贴，避免贴图原有砖缝与自定义尺寸重复。旧材质编号保留，已保存方案与用户 DIY 材质继续可用。

仅重建新增仿石贴图：

```powershell
.\.venv\Scripts\python.exe scripts/build_surface_library.py --common-only
```
