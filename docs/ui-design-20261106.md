# 全站 UI 统一（2026-11-06）

这轮调整以“让空间成为主角、常用操作更容易找到”为目标，不改变生成流程、模型数据、AI 接入配置和草稿保存规则。

## 页面变化

- 品牌统一为「造个家 / LayoutSculpt」，浏览器标题与主题色同步。
- 深绿色导航、暖白色工作面板，统一按钮、边框、圆角、文字层级和键盘焦点。当前导航用金色侧标提示，移动端保留完整文字。
- 新建页突出上传与风格选择，辅助入口保持次要层级；手机宽度下分栏自然堆叠。
- 示例概览把生成户型和复制示例操作移到统计说明之前，减少寻找主要入口的滚动。
- 素材库增强名称、尺寸、选中状态的可读性；悬停不再移动卡片位置。
- 家具 DIY、墙地面 DIY、AI 接入和任务抽屉使用一致的视觉语言；压缩家具 DIY 标题区域，给预览保留更多空间。
- 人工设计的平面辅助入口在桌面合成一行，展开时占满整行；尺寸依据和检查摘要并列，展开详情仍保留完整内容。
- 修正对象列表固定高度与父级布局的冲突，桌面列表随面板伸展、独立滚动；导出按钮补充可访问名称，窄屏图标仍有明确含义。

## 实现与维护

`frontend/src/styles/studio-theme.css` 为统一视觉入口，在 `main.jsx` 的基础与功能样式后引入。规则以 `.studio-shell` 为作用域，功能组件继续负责布局与状态；未引入新依赖、背景图片、持续动画或模糊滤镜。

画布材质、灯光、模型几何和渲染质量不在本轮调整范围。错误、禁用、布局建议等业务状态保留原有语义与反馈。
