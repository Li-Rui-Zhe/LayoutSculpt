# 建筑构件与阳台围护

## 素材库入口

“素材库 → 建筑构件”提供五类、17 个常用住宅构件，支持分类及关键词搜索。卡片使用实际三维渲染的静态缩略图，右侧选中项支持拖动旋转与滚轮缩放，避免每张卡片一直占用 WebGL 上下文。墙面材质的详情也使用立体墙段预览。

| 分类 | 样板 |
| --- | --- |
| 墙体 | 普通实墙、半高隔墙、落地玻璃隔断 |
| 门 | 单开平开门、双开平开门、双扇玻璃移门、卫生间窄门 |
| 窗 | 固定玻璃窗、双扇平开窗、双扇推拉窗、落地固定窗、卫生间磨砂窗 |
| 通道 | 标准无门扇门洞、宽开放通道 |
| 阳台围护 | 实体低栏板、阳台玻璃栏板、阳台封窗玻璃 |

打开已识别或已完成的方案后，可以选择目标墙段并“应用到选中墙段”。从人工设计进入时沿用当前草稿与选中墙段；从素材库应用后进入人工设计三维视图，保留墙段位置和长度、相邻墙体及已有家具，支持撤销。保存生成后才更新正式模型。示例空间可浏览样板，应用功能需要可编辑方案。链接 `?assetType=architecture#library` 支持直接进入新页签。

浏览器回归运行 `node scripts/review/verify_architecture_library.mjs`。脚本生成隔离模型并模拟任务及草稿接口，验证素材库入口、三维卡片、参数、应用与撤销、手机布局及墙面材质预览，不修改真实用户任务。截图和报告位于 `data/visual-review/architecture-library/`。

## 门窗与通道

选中门窗或通道样板，设置宽高、窗台高度及距墙起点位置，选择安装墙段。默认在剩余空位中定位；也可手动输入位置或点击“适配可用空位”。“安装方式”可选择新增，或明确替换同墙段上已有的门、窗或通道。替换会保留对象身份及其他开口，删除或变化的引用不会套用到其他对象。

门扇可调整角度、开启方向及铰链位置。双开门具有两扇门叶，玻璃移门与推拉窗保留双轨错层，平开窗保留独立窗扇与把手，磨砂窗使用独立玻璃材质；窗扇预览为关闭状态，不承诺完整机械开启模拟。无门扇门洞和宽通道直接切出真实墙洞。

门窗样式保存为 `door_style`、`door_material`、`window_style` 和 `glass_type`。原有单开木门、固定清玻璃窗保持默认语义及结构确认兼容；新样式参与结构确认散列。实时预览和 GLB 导出使用对应的部件几何，并重新验证建筑实体截面。门扇摆动仍不代替完整通行与碰撞模拟。

更新后需重启后端才能加载新字段；接口通过健康检查中的 `architecture_openings` 能力标识确认支持。旧后端仍可浏览样板，但会提示重启并阻止安装不兼容的门窗参数。重启后点击“刷新素材”可重新检查。

## 数据与建模

阳台继续使用 `rooms.kind=balcony`。`balcony_type` 区分 `open`（开放）、`enclosed`（封闭）与 `unknown`（待核对）。仅凭家具或房间名称不能确定开放/封闭，也不能把所有相邻墙统一降低。

墙段增加以下围护形式，旧数据默认 `wall`，不自动重写已保存的结构或模型。

| boundary_type | 表现 | 高度 |
| --- | --- | --- |
| wall | 普通实墙，包括阳台两端及室内分隔实墙 | 保留实际层高 |
| parapet | 实体低栏板 | 使用识别或人工输入的实际高度 |
| glass_railing | 实体基座、透明玻璃及细框 | height 为总高，sill_height 为基座高度 |
| glazing | 封闭阳台玻璃及细框，可带实体窗下墙 | 总高按实际封窗；不统一压低为栏板高度 |

在“人工设计 → 墙体 → 围护形式”中逐段调整。切换低栏板时以 1.10 m 作为可修改的展示初值，玻璃栏板以 0.15 m 为基座初值；这些值不代表识别出的实测尺寸。围护总高可在“墙体尺寸与位置”中修改，玻璃基座可单独调整。切换可撤销，不联动降低相邻墙。截断现有开口、承重实墙转换玻璃、基座高于玻璃总高及玻璃栏板安装门窗会被阻止；需要先核对或拆分墙段。

识别、整体复核及局部复核均传输围护类型和基座高度。识别不清时保留待核对状态；结构核对页显示阳台形式及围护类型、高度，开放阳台的可疑高外墙会进入提示。原图没有证据时不自动添加玻璃或降低实墙。

通用建模器与实时预览按同一套总高和基座语义显示玻璃、实体基座和细框。实体饰面只覆盖基座，透明围护不投射整面实墙阴影。GLB 保留完整结构和剖切预览，继续验证实际截面、体积和地板轮廓；围护类型或基座变化会使旧结构确认失效，原有默认实墙的结构散列保持兼容。

阳台家具已包含户外椅、小圆桌、家政柜、洗衣机、洗衣柜及晾衣架。围护是可参数化的建筑墙段，通过上述控件适配长度与高度，不作为固定尺寸家具摆放。

验证覆盖：识别契约及复核往返、原有实墙兼容、单段切换与撤销、开口保护、真实玻璃材质导出、基座饰面限制、GLB 截面验证及普通任务的玻璃阴影。测试使用固定结构，未调用真实 AI；识别准确率仍需用完整原图单独评估。
