## 验证方法

- Python 契约、真实 GLB 导出与 FastAPI 工作流测试。
- Node 测试场景生命周期、剖切、灯光与人工编辑几何。
- 真实 Codex 家具规划及实际户型 GLB 生成，不使用测试替身。
- 本机 Edge 中渲染白天、夜晚、俯视、完整墙体，并检查真实页面灯光、剖切、导出和模型下载。

## 当前边界

该项目仍是根据二维图推断空间的实时三维设计预览。原图未标注尺寸时，尺寸依然依赖估算；家具以可复用通用模型和参数化构件为主，尚不具有商品模型库或离线照片级渲染的细节。家具碰撞使用占地矩形近似，允许地毯与桌椅的合理重叠，尚未建立全屋寻路与精确开门扫掠验证。

## 墙体与视角专项修正

- 实际旧布局的 w28 与 w21 在入口附近平行，墙面净间距约 1 厘米；新增结构检查要求 AI 对照原图确认重复共享墙。出入口遗漏作为质量报告提示，不据此自动添加门。
- 墙体在平面合并后按门窗高度切洞，使用 Manifold 明确执行实体合并。移除各墙块、各高度层之间的内部面，转角和墙面连续。以墙体总体积、转角覆盖、门洞留空、混合墙色没有双倍体积及导出实体闭合检查验证。
- 完整墙体只导出一份实体；封口的 1.2 米剖切预览数据放在 GLB 附加信息中，浏览器创建预览。完整视图与剖切预览互斥显示，下载 GLB 不会叠放两套墙体。
- 三维使用透视相机，俯视保留正交相机；切换时同步后处理相机和环境遮蔽的投影类型。剖切高度固定，不随旋转突然显示高墙。
- 增加对照原图复核墙体和门窗的入口，可为已有任务生成独立复核版本。当前检查仍不能替代逐段对照图纸或精确尺寸确认。
