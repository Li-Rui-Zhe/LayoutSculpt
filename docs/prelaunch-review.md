- 成功率按原图、交付类型和策略版本区分，历史重试不能当作当前新图首次成功率。使用 `scripts/report_generation_success.py` 只读统计，报告不提交到仓库。

## 从原图到三维的约束

1. 上传、识别和可选 AI 复核之后，任务进入“待核对”。在此阶段不规划家具、不生成模型。原图与识别结构并排显示，可进入编辑器修改墙体、房间和门窗。
2. 用户勾选已核对并确认结构。服务端验证结构版本和几何，保存源图摘要、结构摘要与确认时间。等待核对的任务可以取消，重启服务后继续等待核对。
3. 家具规划和照明补充完成后，再检查确认的结构与原图摘要。任何结构漂移都会停止生成。
4. 重新读取实际导出的 GLB，检查建筑实体闭合、墙体体积、每个门窗高度区间的墙体截面、逐房间地板及户型基座轮廓；遗漏和位移会阻止交付。截面面积误差上限为 max(0.002㎡, 周长×0.00002m)，用于容纳 GLB 浮点精度误差。
5. 交付成果提供结构一致性报告。报告区分“人工核对原图”与“模型几何校验”；旧任务复用建模不会被冒充为已由用户核对。材质、家具与灯光调整继承有效的结构确认；主动修改户型结构会产生新的设计版本。

AI 对缺少尺寸或含糊符号的图纸仍可能误判。人工核对负责原图到结构的一致性，几何校验负责结构到 GLB 的一致性。当前校验并非对所有像素的数学证明，也不替代现场尺寸或施工图审核。

## 界面和运行可靠性

- 合并重复的导出入口和三种更新按钮，统一使用“改进方案”选择结构复核、家具重排或三维更新；原任务保留。
- 核对页和人工编辑器都要求明确确认；手机核对页可滚动到确认按钮。
- 状态转变后自动进入对应页面；区分后台生成与等待用户核对。
- 调大主要文字和操作目标，补充键盘焦点、弹窗名称、Escape 关闭与移动任务栏交互。
- 浏览器存储受限时外观、模型选择和编辑草稿继续在内存中工作，并提示保存限制。
- 请求超时和断线有可理解的错误提示，生成与编辑提交防止连续点击。页面异常提供恢复入口。
- 本机 Host 与写入 Origin 校验；UUID 工作目录、产物白名单、终态事务与取消机制保留。
- 确认后的失败重试使用新目录，回归测试确保不会覆盖旧任务产物。

## 启动和维护

2026-10-06 编辑器修复：布局检查使用固定 40px 状态栏，详情按需浮层展开；出现问题、展开、收起及消除时，浏览器实测画布高度变化小于 1px。门窗与通道可通过列表或图上选取安装墙体，目标墙体高亮并显示长度；墙体属性添加入口显式使用当前墙体，切换到门窗保留已选墙体。空间不足时提示具体墙体，不回退到其他墙体。独立浏览器测试数据的报告与截图：`data/visual-review/editor-openings`，复验命令：`node scripts/verify_editor_openings.mjs <完整任务ID>`。

人工设计画布支持滚轮围绕鼠标位置缩放（50%～800%）、空白拖动、空格拖动、中键平移，以及手形导航模式。双击空白或按 0 适配全图，+／− 缩放；对象拖动与视图导航分别处理，导航不写入草稿或占用撤销历史。底部工具移至图纸外。浏览器验收覆盖锚点保持、平移距离、在家具上使用空格与手形模式、正常编辑及撤销，报告位于 `data/visual-review/editor-navigation`；复验命令为 `node scripts/verify_editor_navigation.mjs <完整任务ID>`。

实际验证版本为 `4DC504C5`（完整 ID：4dc504c5b1024a6b8056351c0132a15c）。12 个房间地板、户型轮廓与 8 个墙体高度区间均通过校验，墙体体积 30.345265m³；该版本尚未由用户人工核对原图。浏览器实测白天、夜晚、俯视、完整墙体、效果图导出与 GLB 下载，未出现页面错误。

`backend/requirements.lock.txt` 保存当前验证过的 65 个 Python 包版本（Windows、Python 3.13.5）。同环境复现可安装此文件；开发范围依赖说明仍保留在 requirements-dev.txt。前端版本由 pnpm-lock.yaml 固定。

```powershell
pnpm install --frozen-lockfile
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.lock.txt
pnpm test:backend
pnpm test:frontend
pnpm build
pnpm test:prelaunch
pnpm start
```

正常使用访问 http://127.0.0.1:8000/ 。开发时运行 `pnpm dev:all`，访问 http://127.0.0.1:5173/ 。两种启动方式占用同一 API 端口，选择一种。验收命令使用本机 Edge、8011 端口与独立目录，自动关闭其测试服务。

升级前停止本机服务，备份整个 data 目录和 .env；恢复时在停止服务后整体还原 data。外观与未提交的编辑草稿保存在浏览器本地存储，可在提交三维版本后随模型一起保留。

已知范围：缺少尺寸仍使用估算；右侧阳台入口在现有实际户型中未明确识别，保留提醒；家具碰撞采用占地近似，尚不提供完整寻路、精确门扇扫掠或施工判断。家具为可复用通用资产与参数化构件，实时预览画质仍受资产精细度和浏览器渲染限制。
