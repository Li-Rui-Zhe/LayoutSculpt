# 2026-11-06：减少用户操作，衔接编辑与完整预览

## 目标

用户主要完成“上传户型 → 查看空间 → 调整设计”。检查和恢复由系统承担，普通建议不阻断操作；不能把自动检查通过说成人工核对完成。

## 本轮调整

- 人工设计没有修改时直接返回已有预览；修改后顶部操作变为“更新并预览”，复用已有保存和建模流程，不再直接把用户带到旧成果。
- “更多”中保留“查看上一版（保留草稿）”，需要比较时仍可主动查看旧效果。未结束的放置、绘制、删除、建议预览和无效输入继续有明确保护。
- 画质说明默认收起，随时可展开。编辑仍保留实时同步状态，不增加确认弹窗。
- 开放空间的入口检查采用实际墙体与通道的连通关系，开放厨房可通过客厅连接入口。窄墙缝、窗户、封闭区域不被当作可通行入口。检查不修改墙体，也不按房间名称或 AI 自报置信度放行。
- 灯光数量从交付 GLB 的发光节点读取，区分独立灯具和装饰光源，按灯具 ID 去重，避免示例实际有灯却报告零盏。
- 示例副本生成真实质量与几何校验报告。原创示例明确显示“非图片识别结果”，编辑、效果更新及重试继承来源，不伪造人工核对状态。
- 更换原图时正确沿用 `reasoning_effort`，避免已有推理强度被无声重置。

## 沿用并验证的恢复能力

现有默认生成已经不强制逐阶段人工确认；临时连接失败有限重试，失败主入口为“继续生成”，可复用有效阶段；换模型重新生成是次级选择。本轮没有再造第二套工作流，也没有放松无效几何、失效引用或原图变化的检查。

## 验收

- 前端全量 312 项测试通过，生产构建通过。
- 后端 82 项相关用例覆盖生成、入口检查、光源统计、示例复制、人工设计、临时失败恢复、服务重启恢复。首次测试有一处测试自身共享列表导致对照数据被改动；改为深拷贝后，两项新增端到端用例重跑通过，其余 80 项已通过。
- 独立测试实例使用 `data/workflow-usability-sandbox`，不写用户正式项目。页面实测：复制示例 → 三维设计 → 阅读椅 35° 改为 80° → 更新并预览 → 新版本完成。
- 原版本保持 35°；新版本为 80°；23 件家具、13 处光源保留；几何校验通过；后端结构/家具问题为零；人工编辑没有调用 AI。编辑器仍保留两条使用空间建议，不阻断保存。
- 页面控制台无错误，画质说明默认收起。证据在 `data/workflow-usability-editor.png`、`data/workflow-usability-result.png` 和 `data/workflow-usability-live-verification.json`。
- Three.js 构建仍有大于 500 kB 的分包体积提醒，不影响构建；Python 测试依赖仍有一条弃用提醒。本轮没有伪称消除这些提醒。

## 本机加载状态

前端已构建。停止并重启原 8000 后端的命令被自动审批以 `blocked by policy` 拒绝，旧服务未被停止。因此新增后端检查需要在正常重启本项目后生效；浏览器验收在独立 8001 测试实例完成。未修改正式端口或来源校验配置，未推送 Git。
