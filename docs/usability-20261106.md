# 2026-11-06 操作流程优化

目标：让添加、调整、自动保存与查看成果的下一步更清楚，减少重复提示和无效生成。

## 用户可见变化

- 人工设计没有修改时，主按钮为“查看三维效果”，直接返回已有成果，不新建生成任务。
- 修改后显示“生成最新三维效果”，并简要说明草稿自动保存，完整预览与导出需生成后更新。版本名称只在需要生成时出现。
- 放置、绘制、删除确认、门窗添加、AI 建议预览尚未结束时，按钮直接说明下一步；保留结构核对与无效布局的检查，不因简化 UI 绕过校验。
- 家具尺寸默认折叠，保留旋转、更换款式和原有拖动编辑，尺寸与坐标按需打开。
- 选择家具时，在最多四个候选空间中做有限落点试探，优先选中空间；找到位置就显示占地预览，仍需确认才写入草稿。没有合适建议时继续手选位置或使用“自动找空位”，不自动移动其他家具。
- DIY 家具已有保存成果时直接“选择家具放置位置”，未保存则“保存并选择放置位置”；内嵌修改家具仍用原来的应用按钮。新增直达 DIY 素材库的入口，清理旧筛选避免新素材被隐藏。
- 墙地面按钮说明会进入应用位置选择，不让用户误以为材质已自动覆盖整个户型。
- 普通布局建议不在保存栏重复计数，DIY 保存成功不重复显示另一条同义通知。

## 验证范围

前端全量 306 项测试与生产构建通过。新增覆盖：未修改预览/修改后生成、未完成操作的阻断、建议落点不修改原稿、已占用与隐藏空间处理。没有修改 AI 识别、后端建模或数据格式；没有调用真实 AI。

页面操作在独立示例副本中验收：未修改直接返回原成果；椅子建议落点不立即添加；确认后数量由 23 变为 24 并保持选中；生成最新三维效果成功创建 V2。验收副本归档保留，正式方案不受影响。加载模型的现有落点提示和局部加载反馈继续沿用，不额外增加全屏进度条。
