# 2026-10-26 异常恢复与使用流程优化

## 本轮完成

1. **交付成果**：同一个任务从生成中变为完成后重新核对草稿；等待成果时保留当前页签，不跳回预览。核对失败提供重试。
2. **素材偏好**：首次断线仍能收藏、取消收藏、记录最近使用；待同步操作保存到浏览器。连接恢复时按操作合并后端内容，提供重试入口，避免覆盖其他页面的独立收藏。
3. **材质参数**：墙面、地板参数草稿遇到浏览器存储失败时明确提示保存到素材库，当前参数留在页面。
4. **页面更新**：生产页面核对当前构建标识，发现新版仅提示保存后刷新；可关闭提示，不自动刷新。开发环境继续由 Vite 更新。已经打开且不包含此功能的旧页面，需要先手动刷新一次。
5. **素材列表**：每批展示 48 个卡片，可加载更多；分类、搜索与收藏仍覆盖完整索引。此次限制卡片渲染量，服务端索引仍全量读取，不宣称完成服务端分页。
6. **三维恢复**：主场景和 DIY / 素材预览检测 WebGL 上下文丢失，在画布内提供恢复按钮。保留 CPU 侧场景数据；主场景重新生成环境贴图和后处理缓冲。设备无法恢复时提示先保存，再刷新。
7. **材质历史**：通过时间与 ID 游标加载更早记录，不再只能看到最近 30 条；轮询保留已经加载的历史。
8. **任务续接**：重启后恢复尚未执行的家具、材质排队任务；运行中任务保持中断提示，用户选择重试，避免自动重复调用。正常关闭也保留等待中的任务。
9. **备份导出**：帮助页可下载选定时间点的本机备份。先校验备份，再打包；失败保留原数据。只包含既定项目数据范围，不包含账号凭据；可保存到异盘。恢复仍在下次启动执行，避免替换运行中的数据库。
10. **跨平台验收**：CI 配置 Windows、Mac Apple Silicon 和 Intel。Windows 浏览器验收默认 Edge，Mac 默认 Playwright Chromium，可显式选择浏览器。未运行远程 CI，不等于 Mac 已实机验收。
11. **管理与文档**：两个缓存清理入口使用相同清理规则，仅清理可重建条目；旧 API 保留兼容。修正独立 Codex 模式、浏览器和测试端口说明。
