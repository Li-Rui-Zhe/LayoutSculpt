# 阳台栏板与普通墙的高度

<sub>LayoutSculpt / 使用指南</sub>

墙高表达真实几何高度。识别契约、保存校验和人工设计均允许 0.3～4.5 米，支持窗下矮墙、隔断和阳台栏板；这是模型可表达的范围，不是建筑防护合规范围。

- 开放阳台的外侧栏板与室内完整隔墙分别处理，禁止按房间名整体降墙。
- 原图未标高度时，明确为低栏板的围护可用 1.1 米作展示估算，必须在方案说明中提示核对实际高度。
- 不确定的封窗、侧墙不自动删除或降低。不同高度的连续墙应分段表达。
- 门窗顶部仍不得超过所属墙顶。预览可裁切超高开口，但不会据此修改原始草稿；保存继续校验。
- 自动建议室内吊灯时排除低于 2 米的墙，避免矮栏板拉低全屋灯位。用户已设置的灯位不自动移动。
- 历史项目不会被批量改写；修正应基于最新设计，另存版本，保留原结果。

回归覆盖：`backend/tests/test_low_walls.py`、`frontend/tests/preview-document.test.js`。包括 AI 传输往返、墙段截面、实际 GLB 导出一致性、门窗上界、灯位和原始草稿保护。
