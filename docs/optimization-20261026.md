# 2026-10-26 使用体验与数据保障优化

<sub>LayoutSculpt / 更新记录</sub>

> 历史记录：保留当时的实现与验收事实；当前使用方式请从文档中心开始。

本轮保留 React、FastAPI、SQLite 与 LangGraph 架构，不增加日常登录或审批步骤。

## 按优先顺序实施

1. **三维交互**：高分辨率屏幕拖动时将像素比例临时限制为 1.25，结束约 220 ms 后恢复（最高 2）。完整几何、材质和光照保留；截图前强制恢复。预览与 DIY 编辑均接入。任务轮询内容未变化时复用现有状态，减少无效重绘。
2. **AI 用途提示**：生成页在高级设置外展示当前模型和识图状态，可直接打开模型选择。识图指理解输入图片，不代表图片生成；墙地材质 AI 输出参数后由本机绘制贴图。
3. **保存与导出**：交付页核对本机草稿和浏览器尚未同步的修改，使用已有三方合并规则处理独立修改，有冲突时转到人工设计。点击“更新并导出”创建新版本，成功后下载；重复下载同一份未变化的设计复用本次生成结果。单项文件明确属于当前已生成版本。
4. **加载反馈**：上传、精细预览、设计保存与导出采用公共状态组件；短操作不闪烁，较慢操作显示阶段与说明，未知耗时不显示假百分比。
5. **备份恢复**：数据版本变化前备份；帮助页可安排下次启动备份或恢复、取消安排。恢复前校验摘要并备份当前数据，中途失败回退；进程中断后先恢复事务再启动服务。保留最近 3 份，正在恢复的来源额外保留。不包含账号凭据、`.env` 和浏览器未同步草稿。同磁盘备份不能替代异盘备份。
6. **AI 性能依据**：新增 `scripts/report_pipeline.py`，按版本、模型、强度、阶段、结果与缓存分组统计。已有真实 AI 同组样本较少，因此保留默认结构复核，不据此承诺速度或降低质量标准。
7. **缓存管理**：AI 磁盘缓存每 6 小时检查，保留不超过 30 天、512 MB 的可重建条目；帮助页可主动清理。项目、素材、生成文件不纳入缓存清理。
8. **代码拆分**：交付页、导出草稿比较、人工设计保存栏和操作反馈独立为模块。主编辑器仍较大，后续按功能修改逐步拆分，避免一次重写画布交互。
9. **持续验收**：新增 GitHub Windows 自动检查；浏览器测试自动选择空闲端口及独立数据目录。覆盖人工编辑到最新成果包下载、备份安排取消、小屏与受限存储。未推送时远程 CI 尚未运行。
10. **名称及文档**：界面、标题、README、图标说明统一 LayoutSculpt；更新保存、备份和验收说明。小屏可从导航栏进入帮助与数据管理。
