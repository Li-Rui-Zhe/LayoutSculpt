# 交互与跳转检查

本轮静态盘点覆盖 `frontend/src` 中含交互控件的 50 个 JSX 文件，共 528 个控件定义：333 个按钮、18 个链接、49 个折叠入口、59 个输入框、64 个选择框、5 个文本框。数量按源码定义统计，不等同于动态列表实际渲染的数量。静态检查用于发现缺少处理器、提交类型和空链接等问题，不能替代浏览器行为验证。

## 已修复的问题

| 入口                   | 原有问题                                                                     | 调整                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 在此基础上手绘         | 已有草稿时，确认提示出现在页面上方，点击位置看不到；读取草稿时没有反馈       | 改为原生居中模态框，支持保留旧画布或使用新底图；准备期间禁用重复点击，错误显示在入口附近 |
| 手绘草稿读取           | IndexedDB 阻塞时可能持续等待，事务取消未明确结束；读取失败可能被当作没有旧稿 | 增加连接超时、占用提示和事务取消处理；读取失败时停止切换，保留原有内容                   |
| 页面与 DIY 类型切换    | 先切换页面再写 URL，旧 URL 的恢复事件可能覆盖刚选择的创作类型                | 显式选择同步写入 URL，再更新视图；历史恢复使用最新回退值，避免旧渲染覆盖恢复状态         |
| 素材库 → 打开方案      | 只从当前已加载的任务列表查找，旧方案不在列表时没有任何动作                   | 缺失时查询方案详情；显示打开中，禁止重复请求，不存在时在操作处显示失败原因               |
| 素材库 → 去 DIY 创作   | 不论当前浏览模型还是墙地面材质，都打开家具 DIY                               | 传递当前材质用途；墙面、地板进入对应创作页，人工设计内的地板素材库也支持这一流程         |
| 饰面取样与粘贴         | 换目标时属性栏重建，局部剪贴板随之丢失                                       | 剪贴板提升到编辑器，墙面和地板分别校验用途，跨对象选择后仍可粘贴                         |
| 弹窗中跳转、浏览器返回 | 共享弹窗可能留在新页面上，阻挡后续操作                                       | 页面路由变化时关闭共享弹窗，清理监听器；关闭按钮显式使用普通按钮类型                     |
| 素材排序               | “最近更新”不在 URL 允许值中，排序也没有完整写入 URL                          | 统一允许值、写入和恢复逻辑                                                               |
| 保存镜头               | 成功时没有反馈，场景尚未就绪可能保存无效值，存储失败被忽略                   | 校验场景、明确成功提示，存储失败时说明仅在当前页面保留                                   |
| 表单提交               | 部分提交按钮依赖浏览器默认类型，源码检查难以区分提交与普通操作               | 为五处生成、保存和重命名提交按钮明确声明 `type="submit"`                                 |

## 验证

- 全部前端 Node 测试和生产构建。
- 新增回归测试：排序 URL 恢复、手绘数据库占用及事务取消。
- 浏览器实测：有旧稿确认与取消、无旧稿直接手绘、确认后的底图像素、存储占用错误、跨房间取样粘贴、正确 DIY 类型、前进后退、跳转时关闭弹窗、未加载旧方案打开及方案不存在时的反馈。
- 浏览器测试使用独立上下文，编辑器草稿写入被拦截；核对后确认用户草稿内容和修订号未变化。
- 未执行真实付费 AI 生成、CLI 安装、归档删除或其他会改变用户环境的操作。

后续检查可运行 `pnpm review:interactions`。传入 JSON 输出路径可保留完整控件清单，例如 `node scripts/review/interaction_audit.mjs D:/codex-temp/interaction-inventory.json`。此命令只做源码检查，不点击控件、不执行后台操作。
