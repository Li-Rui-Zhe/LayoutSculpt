## 分类和选型

- 10 个主空间、44 个家具品类；每款都有明确的款式、风格、适用空间、外廓尺寸及说明。
- 空间、品类、风格、最大宽度、收藏和多关键词可组合筛选；例如“沙发 左贵妃”。
- 详情显示同品类款式及尺寸，点击可直接换模型；左右贵妃位以面对沙发为准。
- 卡片优先显示用途、款式和厘米尺寸，统一柔和背景与模型缩略图；外部导入设置收进菜单。
- 无匹配结果时可重置全部筛选，避免被残留的宽度、收藏或分类条件困住。
- 桌面选择款式后滚回预览顶部，手机选择后定位到预览区域。

## 模型和放置

- 米制、Y 轴向上、正面 +Z；实际外廓匹配目录，模型居中且底部落地。
- 新系列包含圆角、分片软包、独立坐垫、门板分缝、五金、支脚和收纳细节。
- 修正检查中发现的转角桌悬空支脚、贵妃位前支撑及底座后移时的支脚位置、穿衣镜支架朝向及上下床端部护栏。
- `kind` 保留素材唯一编号；`furniture_kind` 对应可编辑对象类型。放置使用具体模型的内容快照，左右等变体不会退回默认基础家具。
- 全部模型检查有效几何、落地、尺寸、独立文件、内嵌资源与缩略图；单款少于 10 万三角面、8 MB。
- 原有已保存模型与用户 DIY 素材不重建、不替换。选用新版官方素材后保存，才会进入新设计。

## 可复现构建

```powershell
.venv/Scripts/python.exe scripts/build_home_collection.py
# 只重建指定款式
.venv/Scripts/python.exe scripts/build_home_collection.py --only sofa_chaise_left
# 只更新分类和选型文案
.venv/Scripts/python.exe scripts/build_home_collection.py --metadata-only
```

造型定义位于 `tools/home_collection.py`。先在临时目录生成、检查，再发布到 `assets/furniture/glb`、`thumbnails` 和目录。原有全量 Blender 建库脚本已接入这一步，避免重建时丢失新系列。

Blender 源工程保留早期系列；新家庭系列由 Python / trimesh 生成真实 GLB，各项 `source`、`generator` 字段说明来源。所有官方 GLB 与缩略图均可随 Git 跟踪；用户运行数据仍位于被忽略的 `data`。

## 表达边界

素材用于户型布局和实时三维展示。床体外廓不是床垫采购规格；儿童家具的间距、承重等需以实物产品为准。镜面为材质近似；升降桌、日床等为静态造型，不含机构动画。

本轮仅扩充素材与选型交互，LangGraph / LangChain 的工作流优化留待后续讨论。
