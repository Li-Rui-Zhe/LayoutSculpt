# 三维直接编辑与热更新

## 使用方法

本页介绍人工设计中的热更新。新任务生成期间展示的建筑三维初稿只有查看能力，完整生成后才能进入这里编辑；两种预览接口和文件各自独立，详见 [生成链路](ai-pipeline-design.md)。下方带日期的验收数字是历史记录。

任务提供「平面设计」和「三维设计」两个独立入口，通过 `editorView=plan|scene` 记录当前页面。平面页面只挂载二维画布与绘图、测量等工具；三维页面只挂载三维主画布、光照与模型变换工具，不再使用浮窗。两页使用同一项目草稿，切换保留已完成的编辑，取消未完成的拖动、绘图和放置状态。

三维页面默认「直接拖动」：按住家具、墙体、灯具或门窗即可移动，地板先点选再拖动。家具在水平面移动，门窗沿所属墙面移动，窗台高度限制在墙高以内；俯视下拖窗只沿墙平移。需要时切换「旋转对象 / 缩放对象 / 移动对象」使用手柄（含高度调整）。空白处拖动转动镜头，也可切换「浏览视角」避免移动对象。右侧参数停输 450 毫秒后自动应用，Enter 或离开输入框立即应用；非法值保留在输入框提示，不写入有效设计。Esc 撤回尚未应用的输入，已经应用的修改使用撤销。左侧可添加家具、灯具和门窗；墙体与空间提供坐标录入添加。平面页面保留鼠标绘制墙线与地板边界。

| 对象 | 三维手柄 | 属性面板 |
| --- | --- | --- |
| 家具（内置、导入、DIY） | 平移、离地高度、水平旋转、局部宽深高缩放 | 名称、类型、尺寸、所属空间等 |
| 墙体 | 平移、水平旋转、长度/厚度/高度缩放 | 端点、饰面、两侧及局部墙面等 |
| 地板 / 空间 | 平移、水平旋转、平面缩放 | 边界角点、材质、名称等 |
| 门、窗、通道 | 沿墙移动、宽高缩放；窗可调整窗台高度 | 所属墙、开口类型、门扇等 |
| 灯具 | 平移与高度 | 灯型、开关、流明、色温等 |

墙体会带动相邻端点、附近地板角点和附着开口；移动地板表示修改该空间边界，不会自动搬走其中家具。门、窗、通道各自保持独立对象身份，门和通道保持落地。家具仅允许绕竖直轴旋转，以符合当前户型数据模型。

拖动中按 Esc 取消，松手产生一次撤销记录。沿用人工设计的撤销 / 重做和锁定保护。超出墙高、非法尺寸、房间边界等校验失败时回退到上次有效设计，并在三维窗内显示原因。

增删对象、属性和材质修改沿用现有人工设计入口，自动同步三维。草稿自动保存到当前任务；「保存并生成三维」创建独立成果版本。实时编辑不会改写已交付的 GLB 文件，也不会替用户确认 AI 识别结构。

## 更新流程

1. GLB 元数据将可见网格映射到家具、墙体、空间、开口或灯具。家具整体枢轴包含所属部件（包括水槽、龙头等补件）。
2. 一次手势从开始时快照计算，拖动中更新临时设计和 Three.js 对象，不逐帧调用后端。结构修改使用简化几何实时预览墙洞、地板与灯光；松手后精细建模替换。
3. 松手校验并提交一次草稿历史。有效草稿防抖调用 `POST /api/jobs/{id}/preview`，使用本地建模器，不调用 AI。
4. 请求有序号、取消和过期响应保护；新 GLB 完成解析后替换模型，复用相机与 WebGL，保持视角。构建失败保留当前模型并可重试。
5. 点选使用实际可见模型的快照与稳定对象 ID，避免在新旧模型切换、对象删除后选错对象。

## 验证记录（2026-10-15）

- 前端全量 109 项测试通过，其中新增三维编辑 11 项，覆盖变换、墙窗联动、锁定、稳定选取、几何预览及请求竞态。
- 后端预览接口 2 项通过，包括待核对任务预览不确认结构、不额外调用 AI、非法高度拒绝。
- 建模 / 结构 / 一致性回归 19 项通过；新增厨房补件归属及门窗、灯具点选元数据检查通过。
- 浏览器独立示例副本实测：沙发三维移动、旋转、缩放、撤销；外墙移动带动房间面积变化；窗户沿墙移动；抬升窗户超过墙高被拒绝并回退；草稿同步本机。
- 精细重建是异步完成，结构拖动期间显示简化几何。此功能不提供任意网格顶点雕刻；DIY 家具内部部件仍在原有 DIY 编辑器修改。


### 直接拖动与参数精调补充

- 首次抓取未选中的对象也可直接移动，按实际命中对象创建快照，不依赖 React 的异步选中状态。
- 不足 4 像素的点击不生成撤销记录。指针取消、窗口失焦及 Esc 取消手势；模型替换前清理未结束手势。
- 剖切隐藏区域的门窗透明选取体不再遮挡后面的家具。
- 参数输入随对象切换卸载，待提交计时器取消，避免写到另一个对象。平面页面保持原有提交方式。
- 门窗参数范围随墙长、墙高和其他尺寸联动；右侧有效修改实时更新家具 / 简化建筑，再异步替换精细 GLB，保持相机位置。

- 本轮验证：前端全量 112 项通过；独立示例副本实测家具表面直接拖动、位置联动、单步撤销、角度停输自动更新、窗高超限提示及修正后恢复同步。


### 首屏与重复加载优化

- 首次进入只加载精细 GLB，不显示家具占位体块；没有可用模型时显示加载状态，缓存命中直接复用精细模型。
- 已加载的精细模型在后台同步期间保持可见并允许编辑；替换等待当前手势结束，保留镜头，失败时保留原模型并可重试。
- 后端对已校验、素材已解析的草稿加短期缓存（120 秒，64 MiB 上限）。键包含任务、完整模型输入、风格、家具模式及官方目录修改时间；相同草稿排队后再次检查缓存，避免重复建模。
- 实测示例副本 8.86 MB GLB：首次请求 4.676 秒，相同请求缓存命中 0.041 秒（本机接口耗时，不含浏览器解析）。
- 验证：三维编辑 14 项、真实预览接口 2 项、缓存容量与过期回归 1 项通过。


## 家具添加与落点确认

快捷家具、GLB 素材库和新建 DIY 家具统一进入待放置状态。选款后，在当前平面或三维画布移动鼠标查看占地轮廓，绿色可放、红色冲突。点击放下或使用「自动找空位 → 确认放置」。R 旋转 90°，Esc 取消；壁挂电视自动随墙调整方向。三维放置期间可中键旋转视角、右键平移、滚轮缩放。

预览不写入草稿、不触发三维重建；确认时按最新草稿重新校验边界、实体墙、门口通道、同高度家具及淋浴入口。地毯允许在家具下方，垂直分离的家具允许叠放。壁挂电视只吸附落点 0.75 米内的可用实墙，不自动跳到远处。淋浴保留实墙安装、窗户避让和入口检查。自动找空位优先所选空间，预览显示实际房间，用户确认后才添加。

一次放置对应一次撤销。取消、拖出画布和切换设计页不会添加家具。待放置时禁用保存生成，避免把未落下的家具误认为已保存。精细三维模型在确认后后台同步，现有场景保持显示；落点轮廓不是简化家具替代模型。


## 家具旋转（简化操作）

选中家具后，画布上方直接显示左转 / 右转 45°、90° 按钮与朝向滑条。家具不再使用三维旋转圆环；墙体、地板等结构仍保留原有操作。右侧同样提供按钮和滑条，精确数值放在「输入精确角度」中。

滑条拖动实时更新已有精细模型，松手才提交一次草稿并同步模型，一次撤销恢复整次拖动。Esc 或指针取消恢复拖动前的状态。锁定家具禁止旋转，提交时沿用越界与锁定校验。


## 人工设计页面整理

- 左侧「已放置 / 添加」切换管理对象或添加素材，保留同一草稿与选择状态。
- 三维默认直接拖动，底部通过「操作 / 视角」切换方式；网格在「辅助」中。
- 选中家具后点击画布右上「旋转家具」展开快捷旋转条；右侧默认展开尺寸，其余朝向、位置与高度、微移按需展开。
- 「专注画布」暂时收起两侧面板，点击「展开面板」恢复，不卸载三维模型。
- 平面的测量、原图叠加、批量操作移入辅助工具折叠区；版本名称移入「版本设置」，还原方案在「更多」中。
- 草稿同步、布局检查及保存生成仍保持可见；同步错误保留明确提示和重试入口。
