# 全站优化落地记录（2026-11-06）

目标：减少重复选择和无效等待，让生成、编辑与交付使用一致的检查标准，保留用户已有成果。对应 [26 项排查清单](site-audit-20261106.md)。

## 实现与取舍

| 排查项 | 本轮实现 |
| --- | --- |
| 1 高清导出 | 默认长边 2048 像素，可选 4096；遵守设备纹理上限，导出后恢复编辑分辨率，失败保留已有图片。 |
| 2 检查一致 | 生成报告纳入编辑器的开门、开柜、拉椅、上下床检查。首次生成对最多 8 件无锁定、无联动的落地椅柜尝试最多 20 cm 的调整；只接受无硬冲突、建议减少的结果。人工修改、续作和重建不自动挪动已有家具。 |
| 3 功能完整性 | 增加卫生间洗手台、餐厅餐桌检查。核心缺项不能标为家具全部完成；明确的全屋或指定房间“不需要”要求可排除对应项，不影响其他房间。 |
| 4 默认镜头 | 三维人工设计从能看见室内的一侧进入，避免背景墙遮挡；家具 DIY 的模型正面保持原样。 |
| 5 示例独立物件 | 新复制示例从 23 件增加至 30 件可编辑家具：补出餐桌、岛台、茶几、边几、脚凳和两块地毯。桌面摆件随桌子移动，纯陈设继续分组。GLB 补齐对象索引，首次进入即可选中，保留网格/纹理二进制。 |
| 6 下载反馈 | 成果包等待打包和传输成功后才交给浏览器；422、超时、连接中断在当前页提示并支持重试。离开页面取消未完成下载，不宣称已落盘。 |
| 7 灯光 | 有实际书桌或厨房操作台、缺少近处灯光且净空允许时，补一盏工作区筒灯；保留已有关闭的灯具，遵守 12 盏可编辑灯具上限。 |
| 8–11 材质 DIY | 720 像素预览、2160 像素保存，原始底图保留；改名/光泽不重请求像素预览。属性最多 40 步撤销/重做，同一滑块短间隔操作合并，切换创作方式重置属性历史；画笔历史独立。移除重复保存按钮，明确另存新材质，已保存内容不重复创建，旧项目引用不覆盖。 |
| 12 家具 DIY | 模板增加双人床、沙发、书桌、书架，合计 7 类。常用尺寸先展示，分组及位置/朝向/质感按需展开。 |
| 13–15 页面与状态 | 懒加载立即显示骨架；其他任务的核对数收进“我的方案”。首次进入设置时展示当前可用 Codex，区分环境可用与默认配置尚未保存。 |
| 16 模型能力 | 保留按识图需求禁用不适用模型的规则，未知能力明确标注“识图能力待检测”；不按品牌猜能力，不静默切换服务。 |
| 17–18 对象辨识 | 目标项目默认最新可用版，可搜索和展开历史；保留已选旧版，显示实际版本名。同名家具增加显示编号，不改原名称。 |
| 19 编辑空间 | 建议浮层不再挤压画布。手机首次进入默认专注画布，点“工具与属性”再展开面板；未重写成独立移动端建模界面。 |
| 20 历史来源 | 仅对缺少来源字段、能沿明确版本链找到原创样板 manifest 且源图内容一致的数据，补显示样板身份。不写人工确认，不猜同名项目，不覆盖已有明确来源。 |
| 21 进度 | 百分比说明为实际步骤进度；较久无更新时显示距上次进展时间，不假造匀速百分比和剩余时间。 |
| 22 性能诊断 | Server-Timing 拆分排队、建模、总时长。保留取消、缓存和串行资源保护，未在缺少内存/耗时基准时提高并发。 |
| 23 墙上陈设 | 新样板副本的明确墙体关联随墙平移/旋转；删墙后隐藏并保留，可撤销或重新显示。支持解除关联。不根据距离猜用户家具归属；缩短/降低墙体后仍需检查陈设尺寸。 |
| 24 代码维护 | 导出尺寸、下载、材质历史、墙体联动、样板分组、来源判断、任务灯光拆成独立模块，补行为回归；没有一次性重写所有大型组件。 |
| 25 质量评测 | 新增已保存方案的离线检查命令。真实识图仍沿用人工标注评测入口，本轮未冒充完成真实原图生成评测。 |
| 26 文档 | 文档中心指向当前记录；历史文档中的测试数量与运行状态保留日期语境。 |

## 官方示例

修订 `5e1c94909ee8`，93.2 ㎡、7 个功能分区、13 处模型光源。剖切保留北/西两侧背景墙，其他墙体剖低，完整建筑几何不变；挂画与窗帘遵守承托墙显示规则。

餐桌纵向摆放、椅子放两侧，并调整两盆绿植，为拉椅与床尾柜使用留出空间。新副本获得独立物件，**已有副本和用户草稿不自动替换**。

## 验证

- 前端 **319 项通过**，生产构建通过；Three.js 分包仍有大于 500 kB 的体积提示。
- 后端全量 **736 项通过**，315.95 秒；唯一警告为 Starlette 测试依赖弃用提示。
- 浏览器实测：默认效果图 **2048×1217**，4K **4096×2434**，保持当前构图比例。
- 实测复制示例、30 件家具列表、餐桌独立选中、三维初始视角、同名编号、目标项目筛选、材质改名/撤销与接入状态。
- 最终新版副本离线复查：30 件家具、13 处模型光源，功能缺项、家具问题和通行建议均为空；编辑页也显示几何与通行检查通过。这是规则检查结果，不替代真实使用验收。
- 390×844 窄屏实测：进入三维设计默认专注画布，“工具与属性”可展开，页面宽度与滚动宽度均为 390 像素；验收后恢复桌面尺寸。
- 过程中的旧 720 像素断言、遗漏通行建议的断言已更新；新增测试的一处字典属性写法已修正。上述数量来自最终完整重跑。
- 没有调用付费 AI 重新识别真实原图，不能以本轮测试宣称识图准确率提高。

## 离线复查

```powershell
.venv\Scripts\python.exe -m scripts.review_saved_design data/jobs/<任务ID>/layout.json --output data/design-review.json
```

可传入多个 layout.json；同目录存在 model.glb 时统计实际光源。记录缺项、使用空间问题及检查耗时，不改输入、不调用 AI、不把规则通过当作识别正确。真实户型对照集继续使用 `scripts/quality_cases.py` 的人工标注约束；补齐真实标注仍是后续工作。

灯光规则不等同照明工程计算；小房间不强塞可选设备。低清底图放大不会凭空增加真实细节。旧副本没有明确陈设关联时不猜测迁移。运行数据、草稿、密钥配置、日志与验收截图均在忽略目录，不随代码发布。
