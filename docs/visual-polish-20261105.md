# 家具建模与实时观感优化（2026-11-05）

本轮优先改善真实三维模型和日常查看效果，不增加外景、风格切换或新的 AI 生成步骤。

## 模型与材质

- 官方库保留 83 款家具，其中 62 款 Python 家庭系列更新为 3.3.0。其他系列保持原版本，不能将本次更新理解为 83 款全部重做。
- 茶几、桌板等增加毫米级上下缘倒角；圆柱侧面与倒角使用连续法线，端面和明显硬边继续分离。
- 木材、石材、织物使用各自粗糙度和内嵌微表面法线贴图，织物采用更细的纹理尺度。新增微表面贴图使用 256 px；已有颜色贴图不降分辨率。
- 只合并位置、法线和 UV 一致的重复顶点，不执行减面。保留外廓尺寸、底部落地位置及纹理接缝，继续用原有放置参数。
- 家具嵌入户型时保留与单件预览相同的法线强度，避免同一素材在两处的凹凸表现不同。

## 显示与编辑

- 晴天降低过强的环境补光，调整曝光和接触暗部，日落保留暖色方向光。示例与普通户型共享主要参数，示例只按窗向调整光源方向。
- 主预览降低阴影的法线偏移，改善家具与地面的贴合感。
- 家具 DIY、素材预览、三维人工设计加入统一的 ACES 色调映射与室内环境反射，墙地面 DIY 也采用同一日光参数。
- 单件预览增加接地阴影；人工设计保留轻量渲染，不额外开启整屋实时阴影。相机旋转、平移仍按需绘制，不因镜头移动重建模型。
- 素材库默认关闭辅助网格，需要时仍可手动打开；人工设计的网格行为不变。
- 预览退出时释放环境贴图和阴影资源。

旧任务及其素材快照不会被自动改写。旧模型可直接使用新的显示光照；新增家具、新生成方案使用新版官方素材。需要更新历史方案中的家具造型时，应在人工设计中明确换款并生成新版本。

## 复现与验证

```sh
python scripts/build_home_collection.py
python scripts/build_showcase.py
npm run build
npm run test:frontend
npm run test:backend
```

Windows 可用 `.venv/Scripts/python.exe` 执行前两项。构建过程先在临时目录校验家具的外廓、落地和资源预算，再更新素材库、缩略图和索引。

- 前端 297 项通过，生产构建通过。
- 后端全量运行 679 项；首次有 83 项因旧测试写死 3.2.0 版本失败，另外 596 项通过。同步新版版本断言后，整个官方素材测试文件 86 项全部通过。模型精修、家具复用与示例专项 29 项通过。
- 新增测试检查倒角封闭性、非退化三角形、尺寸不变、圆柱侧面连续与端面硬边、微表面贴图导出保留，以及透明材质不投实心黑影。
- 浏览器实际检查：示例晴天、日落、夜晚与主卧近景，官方双人床预览，历史生成两居室及其三维人工设计的俯视/三维切换；检查过程中未出现控制台错误，未改写原有设计。
- 保留既有 Three.js 大分块提示和 Starlette / AnyIO 弃用警告。本轮不把这些提示计为功能故障。
- 没有调用外部 AI；没有承诺离线电影级光追效果，也没有进行所有设备的帧率测试。
