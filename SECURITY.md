# Security Policy · 安全反馈

[中文](#中文) · [English](#english)

## 中文

造个家（LayoutSculpt）是个人维护的开源项目，欢迎反馈问题、提出建议和参与改进。

### 日常反馈

使用问题、AI 识别偏差、界面 Bug 或功能建议，都可以直接通过 [Issues](https://github.com/Li-Rui-Zhe/LayoutSculpt/issues) 交流。

### 私密报告入口（可选）

如果发现安全问题，或反馈内容涉及敏感信息、不适合公开讨论，可以使用 GitHub 的私密报告入口：

**[提交私密报告 →](https://github.com/Li-Rui-Zhe/LayoutSculpt/security/advisories/new)**

登录 GitHub 后，也可从仓库的 **Security → Report a vulnerability** 进入。简单说明问题、使用版本和复现方式即可。

提交报告或截图前，请隐去 API 密钥、登录信息和个人数据。若入口暂时不可用，可在 Issue 中仅请求私下联系方式，不附上敏感内容。

---

## English

LayoutSculpt (造个家) is an open-source project maintained by an individual. Bug reports, suggestions, and contributions are welcome.

### General feedback

For usage questions, AI recognition errors, UI bugs, or feature suggestions, feel free to open an [Issue](https://github.com/Li-Rui-Zhe/LayoutSculpt/issues).

### Private reporting (optional)

If you find a security issue, or your feedback involves sensitive information that is unsuitable for public discussion, you can use GitHub's private reporting channel:

**[Submit a private report →](https://github.com/Li-Rui-Zhe/LayoutSculpt/security/advisories/new)**

After signing in to GitHub, you can also find it under **Security → Report a vulnerability** in this repository. A brief description, the version you use, and steps to reproduce are enough to get started.

Please redact API keys, login credentials, and personal data from reports and screenshots. If the reporting page is temporarily unavailable, you may open an Issue solely to request a private contact method, without including sensitive details.
