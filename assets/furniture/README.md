本目录提供可直接复用的 `glb/` 家具资产及运行时索引 `catalog.json`。普通户型生成只读取 GLB，不需要 Blender。可选源工程 `habitat-furniture.blend` 不随仓库分发，使用下方脚本可在本地生成。

## 当前目录

当前 `catalog.json` 为 **3.2.0**，共 **83 款、45 个品类、10 个主空间分类**。包括家庭系列、精修床具、台式电脑与笔记本、两款落地晾衣架。当前数量以索引为准；下方 2.2 系列说明为基础资产历史。

普通安装直接使用已提交的 GLB，不需要重新建库。更新家庭系列时使用 `python scripts/build_home_collection.py`（可加 `--only` 选择素材）；电脑与晾衣架的精确命令见 [3.2 说明](../../docs/home-office-assets-v3.2.md)。`scripts/build_assets.py` 是基础 Blender 作者工具，不能把仅重建基础资产的结果当作完整 3.2 目录交付。变更后应同时校验索引、GLB 和缩略图。

## 工作方式

建库脚本只在开发或更新资产时运行一次。每次生成户型时，`glb_builder.py` 根据 `kind` 从 `glb/` 读取家具网格，复用同类网格数据，根据房间位置、旋转和米制尺寸摆放。不会每次重跑建库脚本。

沙发包含分体坐垫、滚边与抱枕；床包含软包床头、枕头、被褥和床尾毯；柜体包含门板、门缝与把手；桌椅包含曲线椅背、细脚；地毯包含包边和流苏。卫浴采用内外壳旋转体，绿植包含分枝和叶片。所有几何和程序纹理由本项目创建，没有第三方模型授权依赖。当前为适合网页展示的轻量家具资产，并非商品级扫描模型。

## 本地构建

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/build_assets.py
```

默认读取 `.env` 的 `BLENDER_PATH`，其次查找 PATH、Windows 默认安装目录和项目内 Blender。此命令仅供家具作者使用，会更新源工程、家具 GLB、索引和 `public/materials/` 贴图。普通上传、重建不需要运行它。

## 替换家具资产

1. 在 Blender 中编辑目标 `asset_<kind>` 集合。
2. 集合只保留一个已经应用修改器的网格；多个零件可合并成一个网格，保留材质槽。
3. 网格数据原点为家具底面中心，Z 朝上，正面朝 -Y；烘焙旋转和缩放。工程中的展示位置可以保留，运行时会重设实例位置。
4. 在 `catalog.json` 更新该资产的 `dimensions`（宽、深、高，米）和版本，并运行导出脚本。交付运行时只需 `glb/` 与索引；实际使用的 GLB 摘要会记录到每次构建报告中。
5. 材质自定义属性 `asset_role` 支持 wood、fabric、accent、stone、white、metal、glass、leaf、dark、soil。运行时按方案风格重映射这些材质；没有映射的自定义材质会保留。
6. `surface_category` 为 walls、floor、fabric 的材质支持网页换材质；其他类型保持原状。
7. 用“保留布局，更新三维效果”重建一个已有户型，检查尺寸和方向。原任务及文件保留，新结果有独立任务记录。

编辑生成脚本中的造型定义后运行建库命令更便于复现。直接编辑 `.blend` 后再运行建库脚本会覆盖手工造型，因此请先将手工版本另存并备份。

## 基础资产历史与制作规范

目录 2.2.0 包含 29 类原创家具，以 Blender 制作的 GLB 为基础；新增两种从原始淋浴网格拆分的集成湿区。模型包含软包缝线、柜门层次、金属五金与卫浴配件。Web 坐标中正面为 +Z（平面图 +Y），床头/靠背为 -Z；旋转 90° 后正面朝平面图左侧。旧方案的低柜、茶几仍保留参数化兼容。

| --- | --- |
| 客厅 | 三人沙发、休闲单椅、55 英寸落地支架电视、55 英寸壁挂电视、格栅电视柜、双层茶几、圆盘边几 |
| 卧室 | 软包双人床、双抽床头柜、双门衣柜 |
| 餐厅与书房 | 实木餐桌、弧面软包实木餐椅、工作书桌、分格书柜 |
| 玄关 | 百叶鞋柜、软包换鞋凳 |
| 厨房与家电 | 厨房地柜、双门冰箱、洗烘一体机、洗碗机、台柜式烤箱 |
| 卫浴 | 台盆浴室柜、坐便器、椭圆浴缸、独立淋浴房、单屏步入式淋浴区、开放式花洒湿区 |
| 软装 | 流苏地毯、陶盆橄榄树 |

television 包含完整落地支架，独立放置；wall_television 是薄机身加背部挂架，底部离地默认 1.05 米，可与低电视柜上下摆放，安装时避开门窗；烤箱包含落地台柜。所有素材可移动、旋转、整体调整尺寸、复制和删除，部件级编辑仍使用 DIY 素材。

餐椅在 2.2.1 修订中重做为完整弧面软包靠背、圆角座垫、连续后腿支柱和四边座框，去除旧款顶部粗木弧与悬置的小靠垫。保持 0.50 × 0.54 × 0.84 米外形及底部中心原点。可运行 `python scripts/build_chair_asset.py` 更新 GLB 和缩略图；它与 Blender 作者工具共用 `tools/chair_mesh.py` 的造型定义，完整建库也会生成同一款餐椅。

`thumbnails/` 为原始模型离线渲染的 320×320 透明 PNG，素材库支持用途分类。建库按单素材隔离进程，合并源工程后导出；已有贴图默认复用，避免重复改写。需要重新制作纹理时可在 Blender 中运行作者脚本并传入 `--rebuild-textures`。

已保存方案和素材快照不会自动替换。普通种类家具重建后使用新版；已绑定快照的家具需从素材库重新添加，以保留原版本的可复现性。

### 淋浴形式与窗户适配

`shower` 自带后方和右侧实体瓷板；`shower_walk_in` 只保留左侧玻璃隔断；`shower_open` 无玻璃围挡。后两者借用卫生间原有实墙，属于原空间，不新增封闭房间。旋转 0° 时花洒朝平面图 -Y，入口朝 +Y。人工设计中选择淋浴家具后可直接切换形式；切换会替换绑定的素材副本，但保留位置、尺寸与朝向，支持撤销。

生成和人工编辑检查实体板遮窗、花洒安装墙面、入口 0.55 米净空、湿区最小 0.8 米宽深。开放式实际施工仍需防水、坡度、排水与挡水设计。示例空间使用单屏步入式，东侧窗前保留采光，入口朝卫生间内部。

无 Blender 环境时，可运行 `python -m scripts.derive_shower_assets`，从现有原创 `shower.glb` 拆分生成两种新素材和缩略图。完整 Blender 造型定义仍保存在 `tools/asset_bathroom.py`，全量建库命令也能生成这两种形式。

- `public/materials/` 保存 512×512 木纹、拼接地板、织物、石材的颜色/法线贴图及三种风格配色。
- 家具 GLB 内嵌贴图；生成的户型 GLB 同样内嵌贴图，无需外部贴图路径。
- 每个成功任务的 `furniture-report.json` 记录建模引擎、资产库版本、家具 GLB 摘要、匹配数量、实例尺寸和基础模型回退情况。
- 未匹配的家具种类可回退到基础几何，并在界面说明；已登记资产的文件损坏或集合缺失会明确报错。
- 网页换材质属于实时预览；下载的 `.glb` 保留生成时材质，效果图导出包含当前预览材质。

## 几何验证

运行 `pnpm test:backend` 验证实际家具 GLB 的几何、贴图及模型构建。旧版 Blender 户型建模器已移除；`tools/` 只保留可选的家具资产制作代码，普通生成由 `backend/app/glb_builder.py` 完成。
