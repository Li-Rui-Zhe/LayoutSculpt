# 栖境家具资产库

本目录提供一份可直接用 Blender 打开的原创家具工程 `habitat-furniture.blend`，以及运行时索引 `catalog.json`。12 个家具集合已标记为 Blender 资产，按网格排列便于编辑。当前版本用 Blender 4.5.9 LTS 构建。

## 工作方式

建库脚本只在开发或更新资产时运行一次。每次生成户型时，`furniture_library.py` 根据 `kind` 从已保存的 `.blend` 追加网格，复用同类网格数据，根据房间位置、旋转和米制尺寸摆放。不会每次重跑建库脚本。

沙发包含分体坐垫、滚边与抱枕；床包含软包床头、枕头、被褥和床尾毯；柜体包含门板、门缝与把手；桌椅包含曲线椅背、细脚；地毯包含包边和流苏。卫浴采用内外壳旋转体，绿植包含分枝和叶片。所有几何和程序纹理由本项目创建，没有第三方模型授权依赖。当前为适合网页展示的轻量家具资产，并非商品级扫描模型。

## 本地构建

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/build_assets.py
```

默认读取 `.env` 的 `BLENDER_PATH`，其次查找 PATH、Windows 默认安装目录和项目内 Blender。推荐固定使用 4.5.9 LTS；更换版本后应重新执行建模验证。此命令会更新本目录的资产工程和索引，以及 `public/materials/` 贴图。普通上传、重建不需要运行它。

## 替换家具资产

1. 在 Blender 中编辑目标 `asset_<kind>` 集合。
2. 集合只保留一个已经应用修改器的网格；多个零件可合并成一个网格，保留材质槽。
3. 网格数据原点为家具底面中心，Z 朝上，正面朝 -Y；烘焙旋转和缩放。工程中的展示位置可以保留，运行时会重设实例位置。
4. 在 `catalog.json` 更新该资产的 `dimensions`（宽、深、高，米）、版本和 SHA-256；目录与 `.blend` 必须一起交付。实际使用的文件摘要也会记录到每次构建报告中。
5. 材质自定义属性 `asset_role` 支持 wood、fabric、accent、stone、white、metal、glass、leaf、dark、soil。运行时按方案风格重映射这些材质；没有映射的自定义材质会保留。
6. `surface_category` 为 walls、floor、fabric 的材质支持网页换材质；其他类型保持原状。
7. 用“更新精细家具”重建一个已有户型，检查尺寸和方向。原任务及文件保留，新结果有独立任务记录。

编辑生成脚本中的造型定义后运行建库命令更便于复现。直接编辑 `.blend` 后再运行建库脚本会覆盖手工造型，因此请先将手工版本另存并备份。

## 贴图与产物

- `public/materials/` 保存 512×512 木纹、拼接地板、织物、石材的颜色/法线贴图及三种风格配色。
- `.blend` 内贴图已打包；导出的 `.glb` 内嵌贴图，无需外部贴图路径。
- 每个成功任务的 `furniture-report.json` 记录 Blender 版本、资产库版本、文件摘要、匹配数量、实例尺寸和基础模型回退情况。
- 未匹配的家具种类可回退到基础几何，并在界面说明；已登记资产的文件损坏或集合缺失会明确报错。
- 网页换材质属于实时预览；下载的 `.blend`/`.glb` 保留生成时材质，效果图导出包含当前预览材质。

## 几何验证

`tools/validate_furniture.py` 可由 Blender 后台运行，传入 `--workspace <任务目录>`；它会检查库内资产的标准尺寸、UV/材质，以及精细家具实例的位移、缩放与贴图打包。当前 12 类资产已做真实 Blender 组装、导出和尺寸验证。
